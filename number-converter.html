About Number Converter

This free Number Converter converts numbers between four common number systems: Decimal, Binary, Octal and Hexadecimal.

Decimal is the standard base-10 number system used in everyday life. Binary uses only 0 and 1 and is widely used by computers.

Octal uses base 8, while hexadecimal uses base 16 and includes numbers 0–9 and letters A–F.
