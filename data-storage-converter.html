Data Storage Converter

The Data Storage Converter lets you convert between commonly used digital data and storage units. You can convert bits, bytes, kilobytes, megabytes, gigabytes, terabytes, petabytes and binary units such as KiB, MiB, GiB, TiB and PiB.

Decimal Storage Units

Decimal storage units use powers of 1,000. For example, 1 kilobyte (KB) is 1,000 bytes, while 1 megabyte (MB) is 1,000,000 bytes.

1 KB = 1,000 bytes
1 MB = 1,000,000 bytes
1 GB = 1,000,000,000 bytes
1 TB = 1,000,000,000,000 bytes

Binary Storage Units

Binary units use powers of 1,024. These units are identified by names such as kibibyte (KiB), mebibyte (MiB), gibibyte (GiB) and tebibyte (TiB).

1 KiB = 1,024 bytes
1 MiB = 1,048,576 bytes
1 GiB = 1,073,741,824 bytes
1 TiB = 1,099,511,627,776 bytes

Bits and Bytes

A bit is the smallest basic unit of digital information and can have a value of 0 or 1. One byte contains 8 bits.

1 Byte = 8 bits

Frequently Asked Questions

How many bits are in one byte?

One byte contains 8 bits.

How many bytes are in one KB?

One decimal kilobyte (KB) is equal to 1,000 bytes.

What is the difference between GB and GiB?

A gigabyte (GB) uses decimal units and equals 1,000,000,000 bytes. A gibibyte (GiB) uses binary units and equals 1,073,741,824 bytes.

How many MB are in one GB?

Using decimal storage units, 1 GB equals 1,000 MB.

How many GB are in one TB?

Using decimal storage units, 1 TB equals 1,000 GB.
