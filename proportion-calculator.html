What Is a Proportion?

A proportion is an equation that states that two ratios are equal. It compares two quantities and shows that they have the same relationship.

A / B = C / D

For example, 2/4 and 6/12 are equal ratios. Both simplify to 1/2, so they form a valid proportion.

How to Solve a Proportion

One common method for solving a proportion is cross multiplication. Multiply the numerator of each fraction by the denominator of the other fraction.

A / B = C / D
A × D = B × C

If D is missing, rearrange the equation:

D = (B × C) / A

Proportion Formulas for Each Missing Value

For the proportion A/B = C/D, use these formulas:

Missing A = (B × C) / D

Missing B = (A × D) / C

Missing C = (A × D) / B

Missing D = (B × C) / A

The required division must be mathematically valid. In the original proportion, B and D are denominators, so neither can be zero.

Worked Example: Find the Missing Fourth Value

Given:
2 / 4 = 6 / D

Step 1: Cross multiply
2 × D = 4 × 6

Step 2: Multiply
2D = 24

Step 3: Divide both sides by 2
D = 24 / 2

Answer: D = 12

Where Are Proportions Used?

  • Cooking: Adjusting recipe quantities for more or fewer people.
  • Maps: Calculating actual distances from map scales.
  • Construction: Working with measurements and scale drawings.
  • Education: Solving ratio and proportion problems in mathematics.
  • Science: Comparing quantities and scaling measurements.
  • Everyday life: Comparing prices, quantities and measurements.

Proportion vs. Ratio

A ratio compares two quantities, while a proportion states that two ratios are equal. For example, 2:4 is a ratio, and 2:4 = 6:12 is a proportion.
