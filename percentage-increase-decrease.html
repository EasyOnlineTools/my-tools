How to Calculate Percentage Increase or Decrease

Percentage change shows how much a value has increased or decreased compared with its original value. It is commonly used to compare prices, salaries, measurements, test scores, business figures and other numerical values.

Percentage Change = ((New Value − Original Value) ÷ Original Value) × 100

If the new value is greater than the original value, the result is a percentage increase.

If the new value is smaller than the original value, the result is a percentage decrease.

Example of Percentage Increase

Suppose the original value is 100 and the new value is 120. The difference is 20.

((120 − 100) ÷ 100) × 100 = 20%

Therefore, the value increased by 20%.

Example of Percentage Decrease

Suppose an original price is 200 and the new price is 150. The difference is -50.

((150 − 200) ÷ 200) × 100 = -25%

Therefore, the value decreased by 25%.

Percentage Increase & Decrease FAQs

What is percentage increase?

Percentage increase measures how much a value has increased compared with its original value. It is expressed as a percentage of the original value.

What is percentage decrease?

Percentage decrease measures how much a value has decreased compared with its original value.

What is the percentage change formula?

The basic formula is:

((New Value − Original Value) ÷ Original Value) × 100

Can I calculate percentage change between two negative numbers?

The calculator can accept negative numerical values. The percentage result is calculated using the absolute value of the original number as the reference amount.

Can I use this calculator for price changes?

Yes. You can use it to calculate changes in product prices, discounts, salaries, expenses, measurements and many other numerical values.
