How to Calculate Percentage Increase or Decrease

The percentage change shows how much a value has increased or decreased compared with its original value.

Percentage Change = ((New Value − Original Value) ÷ Original Value) × 100

If the new value is greater than the original value, the result is a percentage increase.

If the new value is smaller than the original value, the result is a percentage decrease.

Example

Suppose the original value is 100 and the new value is 120. The difference is 20.

((120 − 100) ÷ 100) × 100 = 20%

Therefore, the value increased by 20%.
