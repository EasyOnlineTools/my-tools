What Is Percentage Change?

Percentage change measures the relative difference between an original value and a new value. It tells you how much a quantity has increased or decreased compared with where it started.

It is commonly used to compare changes in product prices, salaries, expenses, sales, population, measurements, marks and business figures.

Percentage Increase and Decrease Formula

For a positive original value, the standard percentage change formula is:

Percentage Change = ((New Value − Original Value) ÷ Original Value) × 100

A positive result indicates an increase, while a negative result indicates a decrease. The absolute value of the result gives the size of the percentage change without its direction.

How to Calculate Percentage Increase

A percentage increase occurs when the new value is greater than the original value. Subtract the original value from the new value, divide the difference by the original value, and multiply by 100.

Percentage Increase = ((New Value − Original Value) ÷ Original Value) × 100

How to Calculate Percentage Decrease

A percentage decrease occurs when the new value is smaller than the original value. Subtract the new value from the original value, divide by the original value, and multiply by 100.

Percentage Decrease = ((Original Value − New Value) ÷ Original Value) × 100

Percentage Increase Example

Suppose a product originally costs 100 and its new price is 120. The price has increased by 20.

((120 − 100) ÷ 100) × 100 = 20%

The product price has increased by 20%.

Percentage Decrease Example

Suppose a product originally costs 200 and its new price is 150. The price has decreased by 50.

((150 − 200) ÷ 200) × 100 = -25%

The negative result indicates a decrease of 25%.

Understanding Percentage Change With Negative Values

Percentage change is straightforward when the original value is positive. When the original value is negative, interpreting a percentage change can be less intuitive.

This calculator uses the absolute value of the original number as the reference amount for negative starting values. This is a calculation convention that allows the tool to return a consistent numerical result. For financial or statistical analysis, consider the meaning of the negative starting value before interpreting the result.

Percentage Change vs. Percentage Difference

Percentage change compares a new value with a specific original value. Percentage difference compares two values without treating either one as the starting point.

Use this calculator when you know which value came first and which value came later. For a comparison where neither value is the original, use a percentage difference calculation instead.

Common Uses of Percentage Increase and Decrease

Percentage change is useful in everyday calculations and many professional fields. Common examples include:

  • Comparing old and new product prices.
  • Calculating salary increases or reductions.
  • Measuring changes in monthly expenses.
  • Comparing sales or business performance.
  • Finding increases or decreases in test scores.
  • Tracking changes in measurements and statistics.

Percentage Increase & Decrease FAQs

What is the formula for percentage increase?

Subtract the original value from the new value, divide the result by the original value, and multiply by 100. This formula applies when the original value is positive and the new value is greater.

What is the formula for percentage decrease?

Subtract the new value from the original value, divide by the original value, and multiply by 100. This gives the percentage decrease when the original value is positive and the new value is smaller.

Can percentage change be negative?

Yes. A negative percentage change indicates that the new value is lower than the original value when the original value is positive. It represents a decrease.

Can I calculate percentage change if the original value is zero?

No. The standard percentage change formula divides by the original value. When the original value is zero, division by zero is undefined, so the percentage change cannot be calculated.

Can I use decimal numbers?

Yes. You can enter whole numbers, decimals and negative values. The calculator displays results rounded to a maximum of six decimal places.

What is the difference between percentage change and percentage increase?

Percentage change describes the relative difference between two values and can be positive or negative. Percentage increase refers specifically to a positive change.

Can I use this calculator for discounts?

Yes. Enter the original price as the original value and the discounted price as the new value. The calculator will show the percentage decrease.

Does this calculator work with negative numbers?

Yes. It accepts negative values and uses the absolute original value as the reference amount. Interpret results involving negative starting values carefully because percentage change can be context-dependent.
